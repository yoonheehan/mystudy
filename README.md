# CS Lab

알고리즘과 백엔드·CS를 함께 공부하는 한국어 SvelteKit 학습 사이트입니다. 메인페이지에서 코딩 실전 24개 문제, 알고리즘 이론 12개 단원과 백엔드·CS 32개 단원을 선택하고, 학습 진도와 이어보기를 확인합니다. 백엔드·CS는 7개 분야에 정의, 생활 비유, 동작 단계, 실무 사례, AWS/Ncloud 적용, 코드, 면접 답변, 꼬리 질문, 확인 문제를 담았습니다.

## 실행

Node.js 22 LTS 환경을 권장합니다.

```sh
npm ci
npm run dev
```

표시되는 로컬 주소를 브라우저에서 엽니다. SvelteKit 실행 결과는 파일을 직접 더블 클릭해 실행하는 방식이 아닙니다.

휴대폰에서는 PC와 같은 공유기/Wi-Fi에 연결한 뒤, 실행 로그의 `Network` 주소를 엽니다. 현재 PC의 주소는 `http://192.168.55.244:5180/`입니다. `npm run dev`와 `npm run preview`는 LAN 접속을 허용하며 포트는 5180으로 고정했습니다. PC가 켜져 있고 서버가 실행 중이어야 합니다. PC의 내부 IP가 바뀌면 새 `Network` 주소를 사용하세요. 이 주소는 같은 네트워크용이며 외부 인터넷에서는 직접 접속할 수 없습니다. 학습 기록은 접속 주소와 브라우저별로 저장되어 PC의 localhost 기록이 모바일로 자동 동기화되지는 않습니다.

```sh
npm run check
npm run build
node build
```

운영에서는 adapter-node의 `ORIGIN`을 실제 사이트 origin으로 지정하고 프록시·TLS·프로세스 관리를 구성하세요. 이 작업에서는 외부 배포를 하지 않았습니다.

## 학습

- `/`는 두 대분류와 통합 진도를 보여주는 학습 홈입니다.
- `/algorithm.html`은 기존 12개 알고리즘 강의이며, `/algorithm`은 실전 풀이 화면으로 연결됩니다. 단계별 그림·자동 재생·Python 코드·연습 문제를 유지했습니다.
- `/backend`는 전체 학습 순서이며 단원을 선택해 읽습니다. 목차에서 검색·북마크·복습을 사용할 수 있습니다.
- 정의 → 이유와 설계 배경 → 역할·동작 → 사례 → Python 예제 → 복습 순서입니다.
- NAT 단원에서 노트북/휴대폰을 골라 주소·포트 변환과 응답 복원을 따라갑니다. 실제 네트워크 설정을 변경하지 않는 모형입니다.
- 검색, 북마크, 학습 지도, 완료 기록, 개인 메모를 제공합니다.
- 틀린 확인 문제는 즉시, 정답 또는 완료한 단원은 24시간 뒤 복습 목록에 나타납니다. 알림 발송 기능은 없습니다.
- 완료·메모·북마크·복습 기록은 브라우저 localStorage에 저장됩니다. 면접 연습 답안은 현재 화면에서만 유지됩니다. 서술형 답변은 자동 채점하지 않습니다.
- `/api/health`는 실제 GET 서버 핸들러이며 프로세스 생존 확인만 제공합니다.
- 원래 `index.html`은 보존했습니다. 기존 알고리즘 학습 화면은 `/algorithm.html`에서도 사용할 수 있습니다.

## 코딩 실전

`/practice`에서 입문·중급·도전 각 8개, 총 24개 문제를 Python로 풉니다. LeetCode와 프로그래머스의 문제/에디터/실행 결과 흐름을 참고해 자체 문제를 작성했습니다. 예시 실행은 무료이며, 전체 제출은 예시·경계·무작위 10개·큰 입력을 검사합니다. 오답은 입력·예상·실제 값과 오류 로그를 펼쳐 확인합니다.

3개 힌트는 순서대로 열리고 누적 8/18/30점 차감됩니다. 같은 회차의 재제출은 2회째부터 2점씩 최대 10점 차감합니다. 전체 통과만 최고 점수에 반영하며 S/A/B/C 등급을 표시합니다. 이미 해결한 문제는 마지막 전체 통과 후 24시간이 지난 무힌트 재도전으로 최고 점수를 최대 10점 보정합니다. 실패해도 최고 점수는 유지합니다. 새 회차는 초안과 힌트를 초기화하고 제출 이력은 남깁니다.

코드는 브라우저의 별도 module Worker에서 실행됩니다. Python은 npm Pyodide 314.0.7의 런타임을 로컬 서버에서 제공합니다. 실행기 초기화 60초, 초기 코드와 각 테스트 4초 제한이며 무한 반복은 Worker 종료로 멈춥니다. Python 표준 라이브러리를 사용할 수 있지만 외부 패키지 설치 기능은 없습니다. 개인 학습용 실행기이며 악성 코드에 대한 보안 격리나 비밀 테스트, 조작 방지 성적 시스템을 제공하지 않습니다.

시간은 현재 기기에서 측정합니다. Python 메모리는 tracemalloc 추가 할당량이며 전체 WASM/브라우저 메모리가 아닙니다. Big-O는 자동 추론하지 않고, 자신의 예상과 기준 풀이의 시간·공간 설명을 비교합니다. 모바일 본문 19px, 코드 17px이며 문제/코드/결과를 전환합니다.

초안·힌트·점수·최근 20회 이력은 `csLabPractice.v1`에 저장됩니다. 주소와 브라우저별 기록이므로 LAN 주소와 localhost 기록은 별개입니다. `npm run test:practice`는 24개 문제의 예시, 생성 케이스, 독립 기준 비교, 감점과 재도전 보정 규칙을 검증합니다. `predev/prebuild/prepreview`는 설치한 Pyodide 실행 파일을 static에 복사합니다.

Pyodide의 MPL-2.0 라이선스와 소스 링크는 `static/licenses/pyodide.txt`에 안내합니다. 런타임은 수정하지 않았습니다.

학습 범위: 코딩 테스트는 Python 전용입니다. 백엔드·CS는 네트워크·OS·DB·서버·클라우드·보안·운영의 공통 이론을 다루며 프로그래밍 예제는 Python으로 제공합니다. SQL, Linux 명령, Dockerfile, YAML, IAM 정책은 실무 구성 예시로 유지합니다. 다른 프로그래밍 언어의 문법·런타임·프레임워크 심화 강의는 포함하지 않습니다.

## 교재형 학습 과정

백엔드 기본 화면은 전체 학습 순서입니다. 컴퓨터와 실행 → 네트워크 → 서버 요청 → 데이터 → 인증·보안 → 클라우드 → 배포·운영의 7장, 32단원으로 읽습니다. 단원 ID와 저장 키는 유지하여 기존 북마크·완료·메모를 보존합니다.

모든 단원은 정의 → 필요한 이유와 설계 배경 → 역할 분담과 동작 → 도입 전후 사례 → Python 예제 → 설명·퀴즈·메모 순서로 한 페이지에서 읽습니다. 추가 클라우드 사례와 DB/인프라 구성은 펼쳐 보는 보충 자료입니다. 탭을 전환하지 않아도 본문을 순서대로 읽을 수 있습니다.

Python 예제는 모두 PC 실행 기준입니다. OS 프로세스·스레드 실습은 웹의 코딩 실행기와 구별합니다. 프로세스 단원의 예제는 `artifacts/process_demo.py`에 저장해 실제 실행을 검증했습니다. 일반적인 GIL 빌드와 free-threaded 조건을 구분합니다. `npm run test:lessons`는 32단원의 배경·사례·역할·Python 예제·공식 출처 연결과 Python 문법을 검사하고, 보충 예제 12개를 실제 실행하여 내장 assertion을 검증합니다. Windows 이벤트 루프 검증에는 일반 실행 환경이 필요할 수 있습니다.

추가로 anjeongkyun 저장소를 통해 6개 단원, backtony 저장소를 통해 다른 6개 단원의 사례·Python 실험·실무 질문을 보강했습니다. 기존 단원 수와 학습 기록 ID는 유지합니다. 출처와 콘텐츠별 이용 조건은 `CONTENT-LICENSE.md`와 각 보충 설명 하단에 표시합니다.

CS 32개 단원의 역할·동작 부분에는 단원별 상태 변화 그림이 있습니다. 이전·다음·자동 재생·정지·속도·단계 슬라이더로 조작합니다. 프로세스/스레드는 공유 힙과 독립 주소 공간, 스택, Queue 전달을 비교합니다. 그림은 고정된 개념 모형이며 실제 OS·DB 실행이나 코드 채점 결과가 아닙니다. 모바일에서는 요소를 세로로 배치하고 큰 글씨를 유지합니다. 운영체제의 움직임 줄이기 설정에서는 시각 효과를 제거합니다.

알고리즘 12개 단원도 단계 선택·재생 속도를 지원합니다. 스택은 세로로 쌓고 큐에는 front/rear를 표시합니다. `/algorithm.html?lesson=스택`처럼 단원을 직접 열 수 있고 코딩 문제의 이론 복습 링크도 해당 단원으로 이동합니다. 기존 `oneStepAlgorithmV1` 기록은 유지합니다.

디자인은 인파 블로그의 JWT 글에서 본문 중심의 읽기 흐름을 참고해 새로 구성했습니다. 원문 글·이미지·CSS는 복제하지 않았습니다. `static/journal-theme.css`가 흰 바탕, 큰 제목, 박스형 본문 목차, 구분된 소제목, 차분한 코드 영역을 제공합니다. 홈은 두 학습 분야의 글 목록 형태이며 백엔드·알고리즘·코딩 실전에도 공통 색감을 적용했습니다. 모바일 본문 19px와 실습 코드 17px를 유지합니다.
